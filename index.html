Finetune

Better tools, right inside Intune.

I designed and built a companion for Microsoft Intune that brings policy search, smart group imports and conflict analysis into an administrator’s existing workflow.

20+ concurrent users

Read the case studyVisit Finetune

Designed around enterprise adoption.

The problem

Routine Intune administration could mean navigating multiple screens or preparing CSV imports with object IDs. I wanted to bring those tasks into the context where administrators already work.

The architecture decision

Finetune runs as a browser extension alongside Intune. It reuses the administrator’s authenticated portal session for Microsoft Graph requests, with access governed by the permissions available to that user. This avoids a separate app registration and additional API permission grants.

The experience

A side panel adds search and analysis tools. In-portal enhancements make information easier to interpret, including translating Windows build numbers into recognisable release names. I designed and built the product end to end.
